# 12. 화면 (대시보드 중심)

메인 문서: `dev/00_MAIN_개발진행.md` · 다음 단계: `dev/13_통합검증_로컬배포.md`

## 목표

`docs/샘플화면_v1.0.html`과 같은 구성으로 실제 데이터를 연결한 로컬 웹 화면을 만든다.

## 화면 목록(기획서 6장)

| 화면 | 구성 |
| --- | --- |
| 대시보드 | 상단 기간 선택(연간·반기·분기·월·주) + 성과 지표 카드 4개(값·직전 대비·추이 그래프), 내 할 일(상태별 건수 필터), 선택 업무 상세(원본 메일 참조, 유사 이력 3단계, AI 지식 요청, G-Knowledge 지식 등록, 완료 확정, 보관 D-day), 표로 보기 |
| 제안된 업무 | 추출 후보·근거 문장, 승인·수정·무시 |
| 주간보고 | 3분류 초안 편집, 미리보기, 승인 후 위키 게시 |
| 업무 히스토리 | 검색·필터, 3단계 결과와 출처 배지 |
| 설정·연결 | 수집 경로, 제외 규칙, 보관 기간 안내, 사이트별 로그인 상태·로그아웃, 로컬 데이터 전체 삭제 |
| 모달 | 로그인 창, G-Knowledge 등록 미리보기, 위키 게시 확인 |

## 작업

1. `src/app/`: FastAPI 라우터 + 서버 렌더링 템플릿 + 정적 JS/CSS. 외부 CDN 미사용(로컬 번들).
2. 그래프: 완료 건수 막대, 나머지 선 그래프(기한 준수율 목표 점선), 진행 중 기간 흐리게, 마우스 오버 툴팁(값·표본), 표로 보기. 이중 축 금지.
3. 보안 헤더: CSP(인라인 스크립트 최소화), X-Frame-Options, 쿠키 HttpOnly·SameSite. 모든 사용자 입력·메일 요약 출력 인코딩. 상태 변경 요청 CSRF 토큰.
4. 브라우저 저장소(localStorage 등)에 업무 내용·자격증명 저장 금지.

## 검증(필수 테스트)

- 주요 화면 렌더링 스모크 테스트(합성 데이터)
- 메일 제목에 `<script>`가 있어도 실행되지 않음
- CSRF 토큰 없는 상태 변경 요청 거부
- Playwright로 기간 버튼 5개 전환 시 오류 없음, 화면 캡처는 로컬에만 저장
