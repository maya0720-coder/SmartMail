# 10. 위키 주간보고 (초안 → 승인 후 게시)

메인 문서: `dev/00_MAIN_개발진행.md` · 다음 단계: `dev/11_성과지표.md`

## 목표

한 주(목~수) 업무로 위키 주간보고 초안을 만들고, 사용자가 미리보기·수정·승인한 뒤 본인 영역만 게시한다.

## 관련 요구사항

WIKI-01 ~ WIKI-06

## 작업

1. `src/domain/weekly/report.py`(WIKI-01): 금주 실적 / 차주 계획 / 이슈·요청으로 자동 분류.
2. 템플릿 매핑(WIKI-02): **기존 위키 페이지(예: ERP_261113) 구조는 `확인 필요`** — 매핑을 설정 파일로 분리하고, 확인 전에는 위 3분류 기본 템플릿으로 미리보기만 제공.
3. `src/integrations/wiki/confluence.py`: Confluence REST API로 조회·수정. 버전 번호로 충돌 검사, 본인 영역만 갱신(WIKI-04). API 허용·인증 방식은 `확인 필요`, 로그인은 04단계.
4. 게시 흐름(WIKI-03): 초안 → 편집 → 미리보기 → 승인 → 게시. 승인 없이 게시하는 코드 경로 금지. 페이지 생성/갱신 선택(WIKI-05), 게시 이력·버전 링크 저장(WIKI-06).
5. 게시 전 마스킹, 초안 생성·게시 시각 이벤트 기록.

## 검증(필수 테스트)

- 기간 경계(목 00:00 ~ 수 23:59)
- 승인 플래그 없이 게시 호출 시 거부
- 다른 사람 영역이 바뀌지 않음(Fake 페이지로 비교)
- 버전 충돌 시 게시 중단·안내
