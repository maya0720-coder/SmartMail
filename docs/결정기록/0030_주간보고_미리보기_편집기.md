# 0030 주간보고를 미리보기 모양 그대로 편집

- 날짜: 2026-11-16
- 상태: 구현(실제 Confluence 본문 표시 확인 필요)
- 관련 요구사항: WIKI-02·03·04·05·06, RET-01, 수정사항 R5

## 배경

- 3칸 목록(금주 실적·차주 계획·이슈)만 편집할 수 있었다. 위키에 보일 표·머리글 모양은 미리보기에서만 보였다.

## 결정

1. **편집기**(`static/js/weekly_editor.js`):
   - 기본 탭 '미리보기 편집'은 contenteditable 영역이다. 머리글(h3·h4)·문단·굵게·목록·표(행·열 추가·삭제)를 쓸 수 있다.
   - '간단 편집' 탭(기존 3칸 목록)은 하위 호환으로 남긴다.
   - 페이지 제목·본인 영역 머리글은 편집 영역 밖에 읽기 전용으로 둔다.
   - 붙여넣기는 글자만 받는다. 끌어 놓기는 막는다.
   - 화면은 HTML 문자열을 대입하지 않는다. DOMParser로 읽은 뒤 허용 노드만 `el()`로 다시 만든다.
2. **서버 정리기**(`domain/weekly/rich.py` `sanitize`, 표준 `html.parser`, 새 의존성 없음):
   - 허용 태그: h2 h3 h4 p br ul ol li strong b em i u table thead tbody tr th td a.
   - 허용 속성: a의 href(`safe_link`로 위키 주소만), td·th의 colspan·rowspan(1~20).
   - script·style·iframe 등은 내용째 지운다. 그 밖의 태그는 태그만 지우고 글자는 남긴다. 주석은 지운다.
   - **h2는 h3으로 낮춘다.** 본인 영역 경계(h2, WIKI-04)를 사용자가 만들거나 다른 사람 영역을 덮지 못하게 하기 위해서다.
   - 중첩 표는 안쪽 표 태그만 지운다. 깨진 HTML은 닫아 준다. 200KB를 넘으면 거부한다.
   - 글자 노드마다 마스킹 후 이스케이프한다.
   - 서식 사이에 걸친 민감정보(예: `010-1234-<b>5678</b>`)가 있으면 미리보기를 거부한다.
3. **게시 흐름**은 기존과 같다(미리보기 → 1회용 번호 nonce → 승인 → 게시, WIKI-03). 미리보기 후 내용이 바뀌면 다시 미리보기해야 한다.
4. **보관**(`domain/weekly/drafts.py`):
   - 자동 보관: 30초마다, 서버 메모리, 주차별 1개, 최대 8주. 앱을 끄면 사라진다.
   - 임시 저장: 사용자가 누를 때. 로컬 DB `weekly_draft`, 보관기간 작업으로 삭제한다.
   - 어느 쪽이든 정리·마스킹한 사본만 둔다. 브라우저 저장소는 쓰지 않는다.
5. **이름·호환**:
   - DB 열 이름은 `snapshot`이다(`html`은 스키마 금지어 검사에 걸림).
   - 초안 응답의 `draft_html`·`page_title`·`own_heading`을 화면이 그대로 되돌려 보내도 422가 나지 않게 받고 무시한다.
6. 슬랙·기타 웹 변환은 HTML을 머리글·항목·문단·표 행으로 풀어 기존 텍스트 규칙을 쓴다(`convert._html_lines`). 표 행은 `a | b`로 쓰고, 위키 표기에서는 `|`를 이스케이프한다.

## 남은 한계

- `wiki_template.toml`은 바꾸지 않았다(편집기 초기값만 템플릿으로 만든다).
- 실제 Confluence에서 표 모양이 그대로 보이는지는 확인하지 않았다(가짜 위키로만 검증).
- 브라우저 `execCommand`는 표준에서 폐기 예정이다. 현재 Chromium·Edge에서는 동작한다.
