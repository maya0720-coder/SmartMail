## 판단 사항

1. **AI-Ground 저장·학습(A-4):** 보낸 내용은 AI-Ground에 저장되고 학습에도 쓰입니다. 이 앱은 아래처럼 처리합니다.
   - 마스킹을 반드시 거친 값만 보냅니다. 전송 직전에 다시 검사하고, 질문에는 고정 안내문과 마스킹된 값만 넣습니다.
   - 메일 원문 대신 요약만 보냅니다.
   - 매 호출을 새 대화로 시작해, 이전 질문이 다음 질문에 섞이지 않게 합니다.
   - 시간이 초과돼도 다시 보내지 않습니다.
   - 'AI-Ground가 개인정보를 저장하지 않는다'는 설명은 AI-Ground 쪽 정책입니다. 이 앱은 그 정책과 관계없이 마스킹합니다.
2. **분류 답변 형식:** g-llm에 '업무/모듈/확신도' 3줄 형식으로 답하게 합니다. 형식이 맞지 않으면 추측하지 않습니다. 실패로 보고 규칙 기반 결과만 씁니다.

## 확인 필요

1. **G-Knowledge 자동화 허용(G-1):** 답변 '없음'을 '공식 API 없음, 금지 규정 없음'으로 해석했습니다. 사내 정보보안에서 화면 자동화를 허용하는지 확인해 주세요. AI-Ground 화면 자동화도 같습니다(A-1은 API가 없다는 답만 있음).
2. **업무 정보 학습 활용(A-4):** 마스킹한 업무 요약(SAP 모듈, 오류 내용, 부서명 등)이 AI-Ground 학습에 쓰여도 되는지 정보보안·개인정보 담당 확인이 필요합니다. 개인정보는 마스킹으로 막습니다. 다만 '회사 업무 내용'이 학습되는 문제는 별개입니다.
3. **화면 선택자:** AI-Ground 채팅 화면(`aiground_fields.toml`)과 G-Knowledge 등록·검색 화면(`gknowledge_fields.toml`)의 선택자가 아직 비어 있습니다. 채워야 실제 호출이 시작됩니다.
4. **검색어 주소 전달(G-5):** 주소 검색을 쓰면 마스킹된 검색어가 G-Knowledge 접속 기록(URL)에 남을 수 있습니다. 입력칸 검색과 같은 내용이 G-Knowledge로 가는 것이라 허용 범위 안으로 봤습니다.

남은 낮음 항목(확인 필요):
