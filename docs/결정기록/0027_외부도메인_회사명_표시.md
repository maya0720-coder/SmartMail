# 0027 외부 메일 요청부서에 발신 도메인의 회사명 표시

- 날짜: 2026-11-16
- 상태: 구현(실제 AI-Ground 회사명 추정 품질 확인 필요)
- 관련 요구사항: TODO-01, AI-01·02, RET-01, 수정사항 R1(기본값 D1)

## 배경

- 외부 메일은 요청부서가 비거나 사내 부서 규칙으로 잘못 채워졌다. 사용자는 어느 회사의 요청인지 한눈에 보고 싶어 했다.

## 결정

1. **구분**(`domain/tasks/requester.py` `RequesterClassifier`): 첫 받은 메일의 발신 도메인을 IDNA로 정규화한 뒤 다음 셋 중 하나로 나눈다.
   - 사내(internal): 설정 `SMARTMAIL_INTERNAL_DOMAINS`, 없으면 Entra 계정 도메인. 데모에서는 `example.invalid`.
   - 무료 메일(freemail): `company_domains.toml`의 `[free_mail]`.
   - 외부(external): 그 밖의 도메인.
   - 업무에는 구분과 도메인 문자열만 저장한다(`task.requester_kind`·`requester_domain`). 주소·이름은 저장하지 않는다.
2. **회사명 결정 순서**(`CompanyResolver`): 사용자 확인 값 > 규칙 파일(`[companies]`, 상위 도메인 포함) > AI 추정 캐시. 셋 다 없으면 도메인 자체를 보여 준다.
3. **AI 추정**(`app/company_job.py`):
   - 백그라운드 주기마다 최대 3개 도메인만 AI-Ground에 묻는다.
   - 보내는 값은 **도메인 문자열 하나뿐**이다. 관문(`gateway.company_name`)이 도메인 꼴(`_DOMAIN_ONLY`)이 아니면 거부한다.
   - 답은 50자 이하·제어문자 없음·URL 아님(`valid_company_name`)만 받는다.
   - 실패하면 6시간 뒤에 다시 시도하고, 그동안은 도메인을 보여 준다.
   - 인터넷·WHOIS 조회는 하지 않는다(기본값 D1).
4. **저장**: `domain_company(domain, company, source, resolved_at)`. 회사명은 개인정보가 아니다. 전체 삭제(`wipe_all`) 대상에 넣었다.
5. **화면**:
   - 요청부서 자리에 회사명과 '외부' 배지를 표시한다. AI 추정 값은 기울임과 '추정' 안내로 구분한다.
   - 상세 화면에서 '회사명 확인'으로 고칠 수 있다.
   - 설정 '외부 회사 도메인'에서 조회·수정·삭제한다(`GET/PUT /api/companies`, `DELETE /api/companies/{domain}`).

## 남은 한계

- 데모 데이터에는 외부 발신 예시가 없다. 화면 확인은 단위·API 테스트로 대신했다.
- 무료 메일은 회사를 알 수 없으므로 '개인 메일'로만 표시한다.
- 회사명 저장소 인터페이스(`CompanyDirectory`)는 `ports.py`가 아니라 `requester.py`에 두었다(이 기능 전용).
