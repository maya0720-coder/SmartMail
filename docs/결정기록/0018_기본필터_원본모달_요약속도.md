# 0018 대시보드 기본 필터 '전체' · 원본 메일 줌 모달 · 요약 속도 개선

- 날짜: 2026-11-13
- 상태: 구현 완료
- 관련 요구사항: TODO-01·02(화면 필터), MAIL-08~10(원본 조회), AI-01·TODO-01(요청 요약)

## 배경

사용자 요청(2026-11-13)
1. 내 할 일의 기본 필터값을 '전체'로 한다.
2. 업무 처리 내용의 메일 원본을 보기 편하게(줌 이벤트/큰 화면) 볼 수 있게 한다.
3. AI-Ground 요청 요약 속도가 너무 느리다 — 개선한다.

## 결정

### 1. 내 할 일 기본 필터 '전체'

- `src/app/static/js/dashboard.js`의 `currentFilter` 기본값을 `todo` → `all`로, `dashboard.html`의 필터 버튼 `on`을 '할 일' → '전체'로 옮겼다.
- '전체'는 무시(dismissed)만 제외하고 제안됨·대기·진행 중·완료 후보·완료를 모두 보여준다.
- 기존 기본값 '할 일'은 제안됨을 숨겨 '제안된 업무' 화면에서 정리하도록 유도한 것이었다(점검 D3). 사용자 요청으로 기본값만 바꾸고, 제안 정리는 상단 배너(`#sugg-banner`)와 '제안된 업무' 화면으로 계속 안내한다. 필터 버튼은 그대로라 사용자가 '할 일'로 바꿀 수 있다.

### 2. 원본 메일 줌 모달(MAIL-08~10)

- 기존에는 상세 패널 안(`resultBox`)에 원본을 작게 끼워 보여줬다. 이를 넓은 모달(`#dlg-mail`, `.modal.xl` 최대 900px)로 바꿨다.
- `dashboard_detail.js::showMail(refId)`가 모달을 열고, `GET /api/mail/{ref_id}`로 원본을 **매번 다시 읽어** 제목·보낸 사람·수신 시각·본문·첨부 파일명을 보여준다. 본문은 `white-space:pre-wrap`으로 줄바꿈을 살리고 최대 높이 안에서 스크롤한다.
- 닫기: ✕ 버튼 · 배경(바깥) 클릭 · Esc. 닫으면 열기 전 요소로 포커스를 돌려준다.
- 원본을 저장하지 않는 원칙(MAIL-08)과 '원문 없음'(MAIL-09), '아웃룩에서 열기'(MAIL-10)는 그대로다. API·마스킹·저장 구조는 바꾸지 않았다(표시 방식만 변경).

### 3. 요약 속도 개선

원인: 요약 작업이 **2분 주기마다 3묶음(최대 18건)만** 처리하고 멈춰, 밀린 요약 사이에 최대 2분의 빈 시간이 생겼다. 10분당 호출 상한(20회) 중 실제로는 15회만 썼다.

- `src/app/summary_job.py`의 `BATCHES_PER_RUN`을 3 → 20으로 올렸다. 한 번 실행하면 남은 묶음을 **연속으로** 처리하고, AI-Ground 호출 상한(10분당 20회)에 닿으면 어댑터(`BrowserGllmAdapter`)가 `TOO_MANY_CALLS`를 올려 자연스럽게 멈춘다. 2분 주기는 '남은 것을 이어서 처리하려고 다시 깨어나는' 용도로만 남는다.
- **호출 상한·최소 간격(3초)·묶음당 최대 6건은 그대로다.** 보호 한계를 낮추지 않고, 기존에 비워 두던 호출 여유(15→최대 20회/10분)와 빈 시간만 없앴다. 결과적으로 로그인 직후 밀린 요약이 끊김 없이 처리된다.
- 묶음 크기(6건)는 게이트웨이의 검증 상한(`test_gateway_rejects_oversized_or_unmasked_batch`, 7건 이상 거부)과 묶여 있어 올리지 않았다. 더 늘리려면 게이트웨이 페이로드 상한과 프롬프트 길이 한도를 함께 재검토해야 한다.

## 검증

- `tests/unit/test_summaries.py`(7건) 통과.
- `tests/integration/test_ui_browser.py`(기존 + 신규 `test_ui_mail_original_opens_in_modal`), `test_ui_layout.py` 통과. 신규 테스트는 데모 메일을 수집해 원본 보기 모달이 열리고 Esc로 닫히는지, 콘솔 오류가 없는지 확인한다.

## 위험·확인 필요

- 실제 요약 속도 체감은 AI-Ground 응답(스트리밍) 시간에 달려 있다. 한 번에 밀린 양이 10분당 20회×6건=120건을 넘으면 그 다음은 2분 뒤 이어서 처리한다.
- 기본 필터 '전체'에서는 제안됨도 목록에 섞여 보인다. 제안을 분리해서 보고 싶으면 '할 일' 필터를 쓴다.
