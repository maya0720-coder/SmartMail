## 결정

- **화면**: 제안된 업무 화면을 트리아지(목록 + 근거 메일)로 바꾼다. 결정지는 **할 일로·나중에·업무 아님** 3종이다.
- **나중에**
  - 상태는 '제안됨'으로 유지하고, `snooze_until`(다음 근무일 08:00 KST)까지 목록에서 숨긴다.
  - 금요일에 누르면 월요일 아침에 다시 보인다.
  - 공휴일은 고려하지 않는다(사내 달력 연동 전).
- **업무 아님 학습**
  - 보낸 사람 주소와 제목 말머리의 키 해시(HMAC-SHA256, 로컬 키)만 로컬에 저장한다.
  - 확신도를 낮추기만 하고 자동으로 제외하지 않는다.
  - 설정 화면에서 초기화할 수 있다(3단계).
- **되돌리기**
  - 결정 후 60초 안에, 같은 화면에서만 허용한다(승인 → 제안됨 복귀 포함).
  - 일반 상태 전이 표(TODO-03, `ALLOWED_TRANSITIONS`)는 바꾸지 않고, '결정 취소' 전용 경로로 처리한다.
- **업무 제목**
  - '대상 + 행동' 규칙으로 쓴다(예: "KSB1 조회 권한 부여").
  - 일반 문구만 남거나 8자 미만이면 AI 요약을 버리고 메일 제목 정리본을 유지한다(점검 D1).
  - 같은 이유로 업무 판별 질문에서 SAP 모듈 문항을 빼고 '업무 여부 + 확신도'만 묻는다(점검 C7). 구분은 규칙으로 판별한다.

## 이유

판단할 근거와 결정지가 부족해서 사용자가 아웃룩을 다시 여는 문제를 없앤다(컨셉안 1장).

## 저장·개인정보

- 저장 필드(스키마 1 → 2)
  - `task`에 `snooze_until`, `confidence`, `reasons`(이유 **코드값** 쉼표 목록), `weekly_section`을 추가한다.
  - `triage_rules` 표를 새로 만든다(키 해시만 저장).
  - 기존 DB는 `ALTER TABLE ... ADD COLUMN`으로 보존한다.
- 메일 원문·근거 문장은 저장하지 않는다(MAIL-08). 상세를 열 때 `GET /api/tasks/{id}/context`가 원본을 다시 읽어 메모리에서만 쓴다.
- 이벤트 detail은 열거형 코드값만 쓴다.
  - `SNOOZED`: detail 없음
  - `TRIAGE_REVERTED`: `approved`·`snoozed`·`dismissed`
- '업무 아님' 학습(3단계 구현)
  - 업무 아님을 고르면 원본 메일을 메모리에서만 다시 읽어 보낸 사람 주소와 첫 `[…]` 말머리를 소문자로 맞춘 뒤 HMAC-SHA256 키 해시로만 바꿔 `triage_rules.dismiss_count`를 1 올린다. 원문은 DB·로그·응답에 남기지 않는다.
  - 키(32바이트)는 Windows DPAPI(현재 사용자 범위)로 감싸 DB와 같은 로컬 데이터 폴더의 `triage_hash.bin`에 둔다(기본 경로는 저장소 작업 트리 안 `data/`이며 `.gitignore`로 커밋만 제외). 데이터 폴더가 복사·유출돼도 같은 PC·같은 Windows 계정이 아니면 키를 풀 수 없다. 데모 모드는 메모리에만 둔다.
  - 키 파일은 임시 파일에 다 쓴 뒤 제자리에 놓고(빈 파일 방지), 읽을 때마다 길이를 검사한다. 손상되면 해시를 만들지 않고(빈 키 대체 없음) 학습만 생략한다. 결정·되돌리기·메일 반영은 멈추지 않는다. 폐기할 때는 덮어쓴 뒤 지운다(SSD에서는 완전 소거가 보장되지 않음).
  - 학습은 감점 기준과 같게 '받은' 첫 메일만 쓴다(내가 보낸 메일의 내 주소는 수집하지 않음). 초기화 API는 `{"confirm": true}` 본문을 요구한다.
  - 보안 검토(2026-11-13): 높음 이상 없음. 중간 2건(키·데이터 분리 → DPAPI 적용, 보관기간 → 사용자 확인 대기), 낮음 6건 반영
  - 감점: 보낸 사람 −0.15×min(n,3), 말머리 −0.1×min(n,3), 하한 0.05. 자동 제외는 하지 않고 이유 코드 `learned_penalty`를 붙인다.
  - 업무 아님을 되돌리면 같은 키 해시(메모리 토큰에 보관)로 1 감소, 0이 되면 행을 지운다.
  - 설정 '업무 아님 학습 초기화'(`DELETE /api/triage-rules`)와 '로컬 데이터 전체 삭제'는 규칙과 키 파일을 함께 폐기한다(예전 해시는 다시 계산할 수 없음).
