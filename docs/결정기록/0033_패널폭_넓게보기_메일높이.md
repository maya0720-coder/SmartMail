# 0033 패널 폭 상한·상세 넓게 보기·메일 영역 높이

- 날짜: 2026-11-17
- 상태: 구현 완료(데모 화면 Playwright 검증)
- 관련 요구사항: 화면(기획서 6장, 12단계), 결정기록 0016(패널 크기 조절)
- 근거 문서: `수정사항_20261117020320.md` N1·U3·U4(사용자 승인 2026-11-17)

## 배경

- N1: 제안된 업무 목록을 오른쪽으로 넓힐 수 없었다. `suggestions.js`의 `max: 560`이 고정 상한이었다. 그래서 넓은 화면에서도 560px에서 멈췄다.
  - 서버 저장 범위(`app/ui_prefs.py`)도 800px이 상한이었다. 화면 상한만 풀면 넓힌 폭을 저장하지 못한다.
- U4: 원본 메일 영역이 `max-height:260px`로 고정이었다. 그래서 큰 화면에서 상세 패널 아래쪽이 비었다.

## 결정

1. **비율 상한**: `splitter.js`의 `max`(px)는 생략할 수 있다. 대신 `maxRatio`(두 패널 합계 대비 비율)를 받는다.
   - 최대 폭 = `min(max, 합계 × maxRatio, 합계 − otherMin)`
   - 제안 목록: `maxRatio 0.7`, 상세 최소 `otherMin 420`. 420px은 상세 필드가 2열로 바뀌는 지점을 고려한 값이다.
   - 대시보드 상세: `max 640` 대신 `maxRatio 0.6`. 목록 최소 520px은 그대로 둔다.
2. **서버 저장 상한**: 800px에서 2400px로 늘렸다. 실제 상한은 화면이 창 크기에 맞춰 다시 적용한다(`fitToWindow`).
3. **폭 프리셋**: 손잡이 우클릭 또는 `Shift+F10`으로 메뉴를 연다. 항목은 `좁게 30% / 보통 40% / 넓게 55% / 기본 폭`이다.
   - 비율은 **손잡이가 조절하는 패널** 기준이다. 제안 화면은 목록, 대시보드는 상세다.
   - 지시서에는 '상세 패널' 프리셋이라고만 되어 있어서 기준을 이렇게 정했다.
4. **상세 넓게 보기(U3)**: 제안 상세 머리에 `[넓게 보기]` 버튼을 두었다. 단축키는 `W`다.
   - 켜면 목록이 48px 열로 접히고 상세가 나머지를 모두 쓴다. 접힌 열을 누르거나 `W`를 다시 누르면 돌아온다.
   - 접힌 상태에서도 `↑↓`로 다음 제안으로 이동할 수 있다.
   - 상태는 서버 설정 `ui_triage_wide`에 저장한다(켜면 "1", 끄면 삭제). 브라우저 저장소는 쓰지 않는다.
   - 900px 이하(서랍 구간)에서는 적용하지 않는다.
   - 대시보드 상세에는 넓게 보기를 넣지 않았다. 대시보드는 폭 프리셋과 비율 상한만 적용했다.
5. **메일 영역 높이(U4)**:
   - 화면 고정형(1025px 이상, 높이 700px 이상)에서는 메일 영역이 상세 패널의 남은 높이를 채운다. 최소 높이는 200px이다.
   - 그 외 화면에서는 최소 200px, 최대 60vh다.
   - '비슷한 지난 업무'는 접힌 상태(`<details>`)로 시작하고 건수만 보여 준다. 메일 영역에 높이를 양보하기 위해서다.
   - `[크게 보기]`는 이미 읽어 온 메일 내용을 복제해 큰 모달로 보여 준다. 서버에 다시 요청하지 않고 저장하지도 않는다. `Esc`로 닫는다.
   - 요청 문장 하이라이트가 처음부터 보이도록 **메일 영역 안에서만** 스크롤한다(상세 패널 전체는 움직이지 않음).
   - 빠른 정리 카드의 메일 영역은 `max(200px, 100dvh − 560px)`로 화면 높이에 맞춘다.
   - 대시보드 상세의 메일 영역(`.d-mail`)은 이미 남은 높이를 채우고 있어서 바꾸지 않았다.

## 보안·개인정보

- 저장하는 값은 폭(숫자)과 켬/끔 표시뿐이다. 업무 내용이나 개인정보는 저장하지 않는다.
- 새 설정 키 `ui_triage_wide`는 저장소 허용 목록에 추가했다. 화면 렌더링에는 `"1"`일 때만 `data-tr-wide="1"`을 내보낸다(조작된 값은 무시).
- 프리셋 메뉴 위치는 CSS 변수(CSSOM)로만 지정한다. 인라인 style 문자열은 쓰지 않는다(CSP 유지).
