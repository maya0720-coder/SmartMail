# 0040 제안된 업무: 체크 유지, 전체·묶음 선택

- 날짜: 2026-11-17
- 상태: 구현 완료
- 관련 요구사항: TODO-02, 결정기록 0036(제안 일괄 처리)
- 근거 문서: `수정사항_20261117072857.md` B1·B2, 결정 D4(기본안 적용)

## 배경

- B1: 제안된 업무에서 체크박스 밖을 클릭하면 체크가 모두 풀렸다. `bulkClick()`이 일반 클릭 때 `BULK.ids.clear()`를 실행했다.
- 탭을 바꿀 때도 체크가 풀렸다(탭 `onclick`의 `BULK.ids.clear()`).
- B2: 전체 선택·해제와 묶음(오늘·어제·이번 주·이전·나중에)별 선택이 없었다.

## 결정

### 1. 선택과 체크 분리(대시보드와 같은 규칙)

| 동작 | 결과 |
|---|---|
| 행 클릭 | 상세만 바꾼다. 체크는 그대로 둔다 |
| 체크박스 클릭 · Space | 그 행 체크 토글 |
| Ctrl/⌘+클릭 | 체크 토글 |
| Shift+클릭 | 앵커부터 범위 체크(현재 페이지 안, 기존 체크 유지) |
| Esc · [선택 해제] | 체크 전체 해제(대시보드도 Esc로 해제) |

- 지금 보고 있는 항목을 체크에 자동으로 넣던 동작(`seedBulk`)은 없앴다. 체크는 사용자가 누른 항목만 담는다. 키보드 Shift+↑↓만 지금 항목과 다음 항목을 함께 체크한다(범위 넓히기).
- 탭·페이지를 바꿔도 체크는 유지한다. 지금 탭 밖의 체크가 있으면 일괄 바에 `n건 선택(다른 탭 포함)`으로 보인다.
- 목록을 다시 불러오면(요약 완료·결정 후) 사라진 업무만 체크에서 뺀다.

### 2. 일괄 작업 바

- 체크가 1건 이상이면 **상세 패널 위**에 일괄 작업 바를 띄운다. 상세는 그대로 보인다(이전에는 2건 이상이면 상세 대신 바만 보였다).
- 모양·문구는 대시보드 `#bulk`와 같다: `n건 선택 · 할 일로 · 나중에 · 업무 아님 · 구분 변경 · 선택 해제`.
- 체크가 있으면 A·S·D 키는 **체크한 항목**에 적용한다. 바에 이 규칙을 적어 둔다. 체크가 없으면 지금처럼 보고 있는 1건에 적용한다.
  - 지시서에 정함이 없어 정했다. 체크 1건일 때도 키가 바의 버튼과 같은 대상에 적용되어야 헷갈리지 않는다고 판단했다.

### 3. 전체·묶음 선택(D4 기본안)

| 위치 | 동작 |
|---|---|
| 목록 머리 체크박스 | 3상태. **현재 탭의 현재 페이지** 전체 체크/해제 |
| 머리 ▾ 메뉴 | `이 탭 전체 선택(n건)` · `모든 탭 전체 선택(n건)` · `전체 해제` |
| 묶음 머리 체크박스 | 3상태. 그 묶음의 항목(**현재 탭, 모든 페이지**). 펼친 '나중에로 미룬 제안'도 묶음 하나 |

- 3상태: 0건이면 빈칸, 일부면 `indeterminate`(`aria-checked="mixed"`), 전부면 체크.
- 대시보드도 같은 규칙으로 맞췄다.
  - 머리 체크는 현재 페이지 3상태다.
  - ▾ 메뉴에 `이 필터 전체 선택(n건)`·`전체 해제`가 있다. 필터와 검색 결과의 모든 페이지가 대상이다.
  - 상태 필터 칩 옆 체크(선택 사항)는 만들지 않았다.

### 4. 한도

- 한도는 서버 일괄 한도와 같은 100건이다. 상수는 `app/triage_tokens.py` `MAX_BULK` **한 곳**에 있다.
  - 서버 검증(`routes/triage_bulk.py`)과 화면(`body[data-bulk-max]` → `bulk_select.js` `BULK_LIMIT`)이 이 값을 쓴다.
- 넘으면 앞에서부터 100건만 체크하고 "100건까지 선택했습니다 · 처리 후 다시 선택해 주세요"를 띄운다.

### 5. 공통화

- `static/js/bulk_select.js`(신규): `toggleOne`·`setMany`·`groupState`·`headState`·`toggleGroup`, ▾ 메뉴(`openBulkMenu`·`closeBulkMenu`).
- 대시보드(`dashboard.js`)와 제안 화면(`triage_bulk.js`)이 함께 쓴다.

### 6. 하지 않은 것

- 빠른 정리 모드에 들어갈 때 "체크한 n건만 정리할까요?"(지시서 '선택')는 이번에 만들지 않았다.

## 보안·개인정보

- 체크 상태는 메모리에만 둔다. 서버·브라우저 저장소에 남기지 않는다.
- 서버는 일괄 요청의 건수(100건)와 상태를 그대로 검증한다(0036). 화면 한도는 편의용이다.
- 모든 글자는 `el()`·`textContent`로만 넣는다.
