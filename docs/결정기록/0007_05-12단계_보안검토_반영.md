## 판단 사항(확인 필요)

1. **처리하지 않은 제안의 보관 기간(M-5):** 기획서에 정해진 값이 없습니다. 그래서 완료 업무와 같은 7일(생성 시각 기준)로 정했습니다. 다른 기간이 필요하면 알려 주세요.
2. **업무 제목 저장(M-6):** MAIL-08은 '참조 ID만 저장'이지만, 업무 목록을 쓰려면 제목이 필요합니다. 업무 제목은 '사용자가 확인한 업무 정보'로 보고 마스킹해서 저장합니다(기획서 5장 '업무 정보·사용자가 확인한 요약만 저장').
3. **화면 표시 마스킹(L-8):** 기획서 5장은 마스킹 대상에 '화면'을 포함합니다. 그러나 로컬 버전에서는 사용자 본인이 자기 메일 원문을 볼 때(원본 보기, 히스토리 초안) 마스킹하지 않습니다. 업무 판단에 원문이 필요하기 때문입니다. 저장되는 값과 외부로 나가는 값은 모두 마스킹합니다. 웹 배포에서 다른 사람이 보는 화면(팀 현황 등)은 마스킹을 적용합니다.
4. **주간보고 게시 이력:** 페이지 ID·버전·링크·시각만 저장하고, 본문은 저장하지 않습니다. WIKI-06에 따라 보관기간 삭제 대상에서 제외합니다(결정기록 0005).

## 남은 일(실제 연동 구현 시)

- **위키 어댑터(M-3):** 인자를 '본인 영역만 마스킹된 값 객체'로 받도록 타입을 바꿉니다. 어댑터 입구에서 마스킹 재검사를 합니다.
- **AI 어댑터(L-12):** 시간 초과가 나도 작업 스레드가 계속 돌 수 있으므로, HTTP 요청 단위의 타임아웃을 둡니다.
- **위키 본인 영역 표시(H-1·H-2):** 이름 대신 고유 앵커(매크로)로 영역을 표시하는 방식을 위키 관리자와 협의합니다.
