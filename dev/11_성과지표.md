# 11. 성과 지표 (대시보드 4개 지표)

메인 문서: `dev/00_MAIN_개발진행.md` · 다음 단계: `dev/12_화면_대시보드.md`

## 목표

대시보드에 표시할 4개 지표를 이벤트·지표 원장에서 자동 계산하고, 연간·반기·분기·월·주 단위로 집계한다(기획서 4.9).

## 관련 요구사항(이 개발 문서에서 부여)

| ID | 지표 | 산식 |
| --- | --- | --- |
| MET-01 | 완료 건수 | 기간 내 완료 확정 업무 수 |
| MET-02 | 기한 준수율 | 기한 내 완료 ÷ 기한이 있는 완료 업무 |
| MET-03 | 지식 등록률 | G-Knowledge 등록 완료 업무 ÷ 완료 업무 |
| MET-04 | 이력 재사용률 | 앱·G-Knowledge에서 해결 ÷ 유사 업무 검색 |

## 작업

1. `src/domain/metrics/periods.py`: 기간 버킷 — 주(목~수), 월, 분기, 반기(1~6월/7~12월), 연(달력). 표시 개수 3/6/8/13/13.
2. `src/domain/metrics/aggregate.py`: 비율은 기간 전체의 분자·분모를 합쳐 계산(주별 비율 평균 금지). 기한 없는 업무는 MET-02 분모 제외, 검색하지 않은 업무는 MET-04 분모 제외. 표본 건수 함께 반환, 5건 미만은 '참고' 표시.
3. 비교: 카드 값은 최근 완료 기간 vs 직전 기간, 진행 중 기간은 `partial` 표시.
4. 목표값은 설정값(기본: 기한 준수율 90% 예시, IE팀 확정 전).
5. API: `GET /api/metrics?grain=year|half|quarter|month|week` (입력값 허용 목록 검증).

## 검증(필수 테스트)

- 기간 경계(수→목 넘어가는 시각, 6/30→7/1, 12/31→1/1)
- 분모 0일 때 '-' 처리
- 비율 합산 방식 검증(주별 평균과 다른 값이 나오는 사례 포함)
- 잘못된 grain 값 거부
